# Contributing

1. Fork the repository and branch from `main`.
2. Use Node.js 24+.
3. Run `npm install` and `npm run check` before opening a pull request.
4. Keep generated `dist/floating-battery-card.js` aligned with source when preparing a release.
5. Keep behavior changes documented in README.md and CHANGELOG.md.

Please keep pull requests focused and include tests for parsing, thresholds, positioning, or lifecycle behavior where applicable.
